# NeurIPS 2026 Overleaf Draft

This folder is an Overleaf-ready draft built on the official NeurIPS 2026 template.

## Files

- `main.tex`: main manuscript
- `references.bib`: bibliography
- `neurips_2026.sty`: official style file from NeurIPS 2026
- `checklist.tex`: official NeurIPS checklist template

## Overleaf

1. Create a new Overleaf project by uploading this folder.
2. Set `main.tex` as the main file if Overleaf does not detect it automatically.
3. Compile with `pdfLaTeX`.

- Method, losses, protocol, and placeholder tables are in place.
